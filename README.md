# Sistem Penggajian Pegawai

## Deskripsi Proyek
Program ini merupakan sistem pengelolaan administrasi penggajian pegawai yang dibuat untuk memudahkan proses manajemen data pegawai dan penggajian. Sistem ini memiliki beberapa fitur utama seperti pengelolaan data pegawai, penambahan data, pencarian data, pengubahan data, penghapusan data, serta perhitungan gaji.

Proyek ini dikembangkan secara berkelompok dengan pembagian tugas agar setiap anggota dapat berkontribusi secara efektif.

## Fitur Utama
* Login dan logout pengguna
* Manajemen data pegawai (tambah, ubah, hapus, cari, tampilkan)
* Pengelolaan data gaji pegawai
* Penyimpanan data berbasis file (.txt) dan PHP
